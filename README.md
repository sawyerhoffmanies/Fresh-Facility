# Fresh Facility

A complete, image-free static website for a professional cleaning and property-care service.

## Files

- `index.html` — semantic homepage markup, services, about, journal article, and contact form.
- `style.css` — responsive visual system, CSS-only illustrations, gradients, glassmorphism, animations, and breakpoints.
- `script.js` — mobile navigation, scroll reveal, active section state, and contact-form feedback.
- `manus-routes.json` — route manifest for the static homepage.

## Use locally

Open `index.html` directly in a browser, or serve the folder with any static HTTP server. No build step or external dependency is required.

## Article note

The homepage includes a complete working draft of the requested article. The second paragraph contains the only article hyperlink: `RMS Cleaning` points to the requested Google Maps URL.
